Esta é uma demonstração com o exemplo do projeto. Para simular os
    seus programas, baixe o est-robot e, no VS Code,
    escolha Terminal → Executar Tarefa → Simular no computador.

  O simulador executa os mesmos bytes que vão para o robô, mas o robô de verdade escorrega, a bateria
  muda a velocidade e os sensores variam com a luz: confira no robô antes da prova.
  Atalhos: Espaço executa/pausa, R reinicia.
