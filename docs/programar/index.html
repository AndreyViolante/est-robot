Como enviar ao robô
  1. Use o Chrome ou o Edge num computador ou Chromebook.
  2. Ligue o robô e conecte o cabo USB. Feche a IDE EST, se estiver aberta: ela conversa com o robô ao mesmo tempo e atrapalha o envio.
  3. Clique em Enviar ao robô. Na primeira vez o navegador mostra uma lista: escolha o robô e clique em Conectar. Nas próximas ele já lembra.
  4. O robô começa a andar logo: deixe-o no chão. Gravar sem executar só grava; inicie pelo menu do robô (pasta vscode).

No Linux, se o robô não aparecer na lista ou não abrir, o sistema precisa liberar o USB para o navegador (regra do udev para o dispositivo 0483:5750).

Na aba Blocos o programa é montado arrastando blocos, e ao lado aparece o Python que eles geram. Levar para o Python copia esse código para a aba Python, para continuar escrevendo.

O programa fica guardado neste navegador. Para levar a outro computador, use Baixar .py; o mesmo arquivo funciona no EST-ROBOT do VS Code.

Abrir .py / .est também abre um projeto da IDE EST (.est): o programa vira Python, com os Meus Blocos como funções, e a página diz se a tradução é exata (os mesmos bytes que a IDE manda).

Depois da primeira visita, esta página funciona sem internet neste navegador: o editor, os blocos, o simulador e o envio ao robô.
