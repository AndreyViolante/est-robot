Robô e navegador

Preparando o Python do navegador…

Pareie o robô no Bluetooth do aparelho antes (senha 1234).

Para enviar ao robô, abra esta página no Chrome ou no Edge de um computador ou Chromebook (pelo USB), ou no Chrome do Android (pelo Bluetooth). Aqui dá para escrever e simular.

Ajuda

Enviar pelo cabo USB

  1. Use o Chrome ou o Edge num computador ou Chromebook.
  2. Ligue o robô e conecte o cabo USB. Feche a IDE EST, se estiver aberta: ela conversa com o robô ao mesmo tempo e atrapalha o envio.
  3. Clique em Enviar ao robô. Na primeira vez o navegador mostra uma lista: escolha o robô e clique em Conectar. Nas próximas ele já lembra.
  4. O robô começa a andar logo: deixe-o no chão. Para só gravar, use a setinha ao lado de Enviar ao robô e Gravar sem executar; depois inicie pelo menu do robô (pasta vscode).

No Linux, se o robô não aparecer na lista ou não abrir, o sistema precisa liberar o USB para o navegador (regra do udev para o dispositivo 0483:5750).

Celular e tablet Android

No Chrome, ligue o Bluetooth do robô e pareie nas configurações do aparelho (a senha costuma ser 1234). Depois use Enviar por Bluetooth e escolha o robô na lista. O envio por Bluetooth ainda não foi conferido no robô: se não funcionar, conte o que apareceu nas mensagens. Instalar, no alto, põe esta página na tela inicial, como um aplicativo.

Blocos e Python

Na aba Blocos o programa é montado arrastando blocos, e ao lado aparece o Python que eles geram. Levar para o Python copia esse código para a aba Python, para continuar escrevendo, e Trazer do Python faz o caminho de volta: o programa da aba Python vira blocos. O que ainda não tem bloco vira um bloco cinza "Python", com a linha como está.

Arquivos e versões

O programa fica guardado neste navegador, e Versões deixa voltar para o que estava antes (a cada simulação ou envio, no Ctrl+S, antes de abrir outro programa e a cada 5 minutos). No menu Arquivo: Baixar .py leva o programa para outro computador (o mesmo arquivo funciona no EST-LAB do VS Code); Abrir .py ou .est também abre um projeto da IDE EST, com os Meus Blocos como funções; Salvar para a IDE EST faz o caminho de volta; e Copiar link do programa gera um link com o programa dentro, para mandar ao professor (nada fica guardado em servidor).

Sem internet

Depois da primeira visita, esta página funciona sem internet neste navegador: o editor, os blocos, o simulador e o envio ao robô.
